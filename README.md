# Old School Document Classification

This project is a simple Python starter for document classification work.

## Project structure

- `script.py` - main Python script
- `.env` - local environment variables
- `.gitignore` - ignores local environment and generated files

## Getting started

1. Create and activate a virtual environment:
   - Windows PowerShell:
     `python -m venv .venv`
     `.venv\Scripts\Activate.ps1`
   - Windows Command Prompt:
     `python -m venv .venv`
     `.venv\Scripts\activate.bat`
2. Install dependencies if needed:
   `pip install -r requirements.txt`
3. Run the script:
   `python script.py`

## Environment variables

Edit the `.env` file with any local configuration values you need.

## Notes

This is intentionally kept simple for now while you build out the project.
